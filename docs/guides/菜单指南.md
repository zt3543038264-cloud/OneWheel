# 当前菜单操作

更新：2026-11-16。只保留已交付的新入口；其他菜单以当前固件显示为准。

## 主轮持续原始 PWM

`Params → Motor`：
- `Duty Drv`：幅值 0–3500，步长 10。
- `C Raw + HOLD` / `C Raw - HOLD`：持续正/负原始 PWM，不应用方向和死区补偿。
- `C Raw STOP`、Back 或全局 Stop：结束输出；换方向先停止，再启动另一方向。

此入口不是平衡模式，不驱动飞轮，不是电流控制或硬件看门狗。停止命令与实际机械停稳应区分。
目前用户暂停主轮测试，不自动发起试验。

## Storage

在 Stop 状态测试手动 Save，记录屏幕结果。当前自动开机读取关闭，重启参数不恢复不能单独说明写入失败。详见 [存储状态](../STORAGE_SAFETY.md)。
