# 控制调试指南

核对日期：2026-10-08（角度外环 1 kHz）；默认值按最新实车读回与确认更新，已归一化菜单方向和增益，表中 PID/速度为便于阅读的近似显示，精确数值见参数参考。依据 [control.c](../../code/Controller/control.c)、[pid.c](../../code/Common/pid.c)、[config.h](../../code/config.h) 和 [menu.c](../../code/Menu/menu.c)。以下为当前程序，不再沿用旧版增量 Roll、全零默认值或旧波形通道的整定笔记。

## 1. 当前默认值与控制律

所有数值是编译默认值；Flash 可以覆盖。完整范围、步长见 [参数参考](参数参考.md)。

| 环 | 周期 | 实现 | 默认 Kp / Ki / Kd |
|---|---:|---|---|
| Roll rate | 1 ms | 位置式，条件积分及输出限幅 | 20 / 0 / 8（内部 +20 / 0 / -8） |
| Roll angle | 1 ms | 位置式 | 36 / 0 / 0 |
| Roll recovery | 20 ms | 位置式 | 0.0015 / 0 / 0 |
| Pitch rate | 1 ms | 增量式，限幅及抗饱和 | 20 / 0.64 / 0 |
| Pitch angle | 1 ms | 位置式 | 9 / 0 / 0 |
| Pitch speed | 20 ms | 位置式，限幅及条件积分 | 0.06 / 0.002 / 0 |
| Yaw rate | 1 ms | 位置式 | 56 / 0 / 0（内部 -56 / 0 / 0） |
| Yaw angle | 1 ms | 位置式，连续航向 | 18 / 0 / 0 |

2026-10-08 起，三个角度外环与姿态角发布统一为 1 ms（1 kHz），适用于正式串级和单轴测试。菜单、Flash、cfg 的角度 Kp/Ki/Kd 仍按原 5 ms 基准显示和保存：内部 Kp 不变、Ki×0.2、Kd×5，积分累计限幅×5；初始化和在线刷新都自动换算。现有参数无需手动重算或重新保存。速度/回收/方向仍为 20 ms，压弯/编码器/Path/CPU1 反馈仍为 5 ms。周期换算保持积分与微分的时间尺度，不等于实车动态完全一致。详见 [1 kHz 试验说明](../design/角度外环1kHz试验说明.md)。

位置式为 `Kp·e + Ki·Σe + Kd·(e-e_prev)`；增量式将 `Kp·Δe + Ki·e + Kd·Δ²e` 累加到上次输出。实现没有显式乘/除 dt，增益与调用周期绑定。不能把某一种算法的 Ki 或 Kd 调法直接套到另一种。

当前 `r_angle_ki=0`，`p_vel_ki=0.002`，`r_rate_kd=8`（内部 D 系数 -8）。旧文档“Roll 角度 Ki 必须给”“全部 Kd 永远为 0”“Roll rate 先加 Ki”均不对应当前基线。占空比不是已标定的力矩或转速指令，不能只凭占空比恒定就断言某个积分环必须启用。

### 反馈与误差方向

按当前完整串级的实际表达式：

| 环节 | 误差 / 目标 |
|---|---|
| Roll 回收 | `RPM_A - RPM_B`，直接反馈，无额外低通 |
| Roll 目标 | `roll_zero + lean_offset - recovery_output`，相对机械零点限 ±10° |
| Roll angle | `att.roll - roll_target` |
| Roll rate | `att.roll_rate + r_angle_pid.out` |
| Pitch speed | `C_counts_20ms - speed_ramp`，输出倾角限 ±8° |
| Pitch angle | `p_vel_pid.out - att.pitch + pitch_zero` |
| Pitch rate | `-pitch_euler_rate() + p_angle_pid.out` |
| Yaw angle | `yaw_target - imu_get_angle_yaw()` |
| Yaw rate | `y_angle_pid.out - imu.gyro_z` |

2026-09-12 起，Pitch 正式串级（Balance/Run/Remote/里程测试）和 Pitch Rate/Angle/Speed 单轴测试统一使用 `pitch_euler_rate() = gyro_y*cos(att.roll) - gyro_z*sin(att.roll)`，单位 °/s，与欧拉 Pitch 角度外环一致。使用绝对姿态 Roll，不扣机械平衡零点。`att.pitch_rate` 本身仍保存机体系 gyro_y；A+ 原始输入、Roll/Yaw 控制和 CPU1 坡道反馈语义不变。投影系数在 Roll 值改变时重算（正常为 1 ms 姿态角发布；A+ 核心每 1 ms 更新），最新陀螺反馈仍每 1 ms 使用；启停/测试切换后首拍重新建立缓存。2026-09-12 的坐标投影修改未改变 PID 或 Flash；2026-10-08 的角度外环 1 kHz 试验使用上述周期适配。

Yaw 使用连续角，不改成 ±180° 包装角。Roll 回收输出自身没有独立限幅，角度环输出也没有旧 `r_angle_limit`；最终由 Roll 合成目标 ±10° 与 rate 输出限幅约束。`r_rcy_tau`、`r_rcy_limit` 已不存在。

### 输出与保护

A/B 理想混控为 `A=-Roll+Yaw`、`B=Roll+Yaw`。先夹住 Roll，再将 Yaw 限制到剩余余量，A/B 输出上限 10000。C 控制输出限幅 8000，驱动层有 120 死区补偿。Test 使用同样的飞轮/C 控制限幅。

当前默认六个方向参数均 +1，表示已确认的实车基准；C 输出、C 编码器、IMU 和转向的底层符号仍为 -1。飞轮限速 8000 RPM，fly_slew=0；保护角 20°/50°；Roll/Pitch 零点约 -0.6°/-3°。IMU +1 对应当前前向（原车尾），修改后须保存 Zero 并静止重启。A/B 的磁编码器与 FOC 在外置驱动板，TC264 仍发送原 UART 指令、接收 RPM。参见 [方向基准整理](../design/方向基准整理.md)。


## 2. 模式与退出行为

| 模式 | 启动入口 | 实际行为与停止 |
|---|---|---|
| STOP | 上电 / `control_stop()` | 三电机清零，A/B 软件刹车锁定 |
| Jog | Params → Motor | 单轮持续点动；任一 Jog 动作确认、离页或 A/B 失联/超速停止 |
| 单轴 Test | Roll/Pitch/Yaw 页 Rate/Angle/Speed | 只启用指定轴至最高环；同一动作再次确认或离页停止 |
| Balance | Run Test → Balance | 两次确认，三轴全闭环、零速、锁存启动航向；再次确认或返回完全停止 |
| Remote | Run Test → Remote | 两次确认，三轴闭环接收无线速度/相对航向；超时归零速度但仍保持平衡 |
| Path | 主菜单 Path | 手推/遥控示教、保存和预览；两次确认启动相对路径导航，正常终点保留平衡，返回/stop 完全停机 |
| 1m Test | Params → Odometry | 一次确认 Start 1m Test 即启动三轴平衡直行；达到 1m 后 DONE，仍平衡 |
| Run | 主菜单 Run | 两次确认，视觉速度/转向及压弯；结束行驶可保留平衡 |

Roll/Pitch 的 Rate 只开内环，Angle 再加角度环，Speed 再加回收/速度环。Yaw 只有 Rate 和 Angle。Pitch Test 的 A/B 被锁停，Roll/Yaw Test 不靠 C 轮闭环解耦，应使用适合该轴的台架。

`START_BALANCE` 也是 Run、Remote、Path 和里程验证使用的基础状态；不能仅凭它判定“独立 Balance”。`START_DRIVE_ONLY` 是内部 C 轮分支，当前没有独立菜单发车入口。

Run 运行中再按 Run 调用 `control_run_stop()`：目标速度/斜坡清零，退出 Run 并锁存当前航向，仍是 Balance；再按 Run 才完全锁停。视觉年龄 ≥100 ms、连续丢线 ≥600 ms 也调用 `run_hold_balance()`。斑马线请求先锁存里程基准，行驶 `zebra_stop_offset_m`（默认 0.15m）后减速，斜坡接近 0 且 C 计数 ≤3 才结束 Run。

基础状态非 STOP 时返回键、以及完整串口 `stop` 调用公共完全停机路径。Jog 的参数编辑状态第一次返回只退出编辑，第二次离页才停止，见菜单指南。IMU/姿态/驱动、保护角、飞轮超速和非法输出等控制安全闸会停回 STOP。菜单提示或 `run_active=0` 都不能替代完整状态判定。

## 3. 正式 Run 的速度、转向与压弯

发车必须先处于 STOP，CPU1 READY，视觉年龄 <100 ms，IPM 和循迹有效，并通过 Balance 的姿态/标定/驱动和起步保护角检查。发车后等待 CPU1 返回带 `run_active` 的结果，才启用本次 Run 的视觉规划和终点请求。

- 速度：直道与弯道速度随曲率插值，元素覆盖为相应分段速度；普通有效道路还受拟合质量限制，低质量限速具有 0.50 m/s 的编译期下限（受直道速度上限约束）。再应用视觉绝对限速和共模动量降权。实际丢线分支直接采用 Lost 速度，600 ms 后退出。
- 默认 Straight/Curve/Cross/Ring/Ramp 约为 1.20/0.80/0.80/1.00/1.00 m/s，Lost 为 0.20 m/s；均不超过 Straight 和绝对上限 1.50 m/s。不要把这些值称为零速或台架起步值。
- Run 斜坡使用 m/s²，默认加速 0.50、减速 1.00；Remote/1m Test 仍用每 20 ms 增加 1.2、减少 1.9 counts 的步长。
- 方向每 20 ms 由像素偏差、航向误差、实测速度×曲率前馈及方向差分合成。默认系数约为 1.60、1.00、60、0；像素误差新值权重 0.25。
- 2026-09-12 起，共用 `DIRECTION_CAMERA_LIMIT` 从 5000 提高到 15000，图像发布、CPU0 接收和方向计算同步生效；除以权重和 345 后，像素偏差范围由约 ±14.49 扩到 ±43.48。小偏差稳态增益不变，大偏差继续增加像素项纠偏请求；大弯后滤波状态更大，回中瞬态可能变化。此项是编译常量，不增加菜单/cfg 参数，也不需要重置 Flash。
- 目标 Yaw rate 限 ±120°/s 并按动量权限缩减，每 1 ms 限制变化率 600°/s² 后积分为连续航向，目标超前角限 ±35°。
- HOLD 或失效循迹保持进入时航向；不是每帧把当前航向再加一个像素增益。
- 压弯每 5 ms 根据持续转弯率指令和低通实际车速生成：方向预压弯＋`v*r/g` 速度项，带 2°/s 连续死区、0.05～0.30 m/s 速度淡入。有效视觉的正式 Run 启用；Path 导航使用自己的持续转向率指令进入同一压弯公式，不要求视觉有效。两者都不使用原始像素偏差门控或航向跟踪误差。默认 Turn Kp≈0.01、Speed Kp=0.7、Slew=18°/s、Lean Max≈6°；压弯及合成目标硬上限仍为 10°。公式、参数迁移与对照方法见 [压弯控制说明](../design/压弯控制说明.md)。
- 共模 `(RPM_A+RPM_B)/2` 从 2500 到 6000 RPM 将权限从 1 降至 0.25。它与差模回收 `RPM_A-RPM_B` 是不同反馈；同向增速不能直接归因于 Roll 回收失效。

## 4. 当前调试顺序

1. 静止上电，确认 IMU 标定、姿态收敛和驱动链路。先读运行参数并留存，不能假设它们等于源码默认值。
2. 架空验证 Jog：C 正向驱动车向前、编码器向前计数为正；A/B 检查实际旋转方向及回读映射。A/B 的方向参数同时改变指令和回读，软件显示同号本身不能独立证明机械方向正确。
3. 用限制其他自由度的台架依次验证 Roll Rate/Angle、Pitch Rate/Angle/Speed、Roll Speed、Yaw Rate/Angle。从当前已知参数作小步调整，一次改一个量，记录现象和恢复值。Rate/Angle 未启用外环，不用于长时间放手平衡验收。
4. 在 Zero 页手动调整机械零点并保存；当前没有 Capture Zero。进入独立 Balance，观察三轴响应、飞轮差模/共模与 C 轮漂移。
5. 停车后用 Odometry 的 Reset Counter，手推准确 1m，将计数换算为 `odom_counts_per_m` 并保存；再用受约束的 1m Test 验证距离。Done 后仍需停止平衡。
6. 按视觉指南核对图像、IPM 和元素，再选择符合现场约束的 Run 速度。完整记录发车前至结束后至少 2 秒的数据。

变更方向、机械零点或编码器尺度后，重新核对相关闭环符号和限幅；不要用“以后只能改 PID 符号”替代接线与测量。

## 5. 参数权限、观测和诊断

UART2 用 `cfg:get/set/schema/status/save`，不支持旧 `r_rate_kp 12` 写法。STOP 可修改运行参数；Jog 不允许 cfg 写参数；单轴 Test 只放行当前启用环的 PID；基础状态为 Balance 时放行 24 个 PID，并开放 Run/Lean 两组共 14 项速度、转向和压弯参数（包含正式 Run、Remote 和里程测试）。这些非 PID 项需 Schema bit4 与 stat 权限 bit24 同时确认；其余非 PID 参数仍需 STOP。Path 采集、导航和导航终点 Balance 保持期间，菜单参数编辑与 cfg 写权限均关闭；完全停止后恢复。菜单的编辑限制并不完全等同 cfg，具体差异见 [源码核对记录](../../tools/unicycle_station/docs/source-audit.md)。

独立 Test/Balance 没有旧 `roll/pit/yaw/bal` 标签。最新版固件与上位机完成 hello 后，单轴 Test 或 START_BALANCE 基础状态会自动发送 25 通道 `run:` 诊断波形，并保留辅助 `att`；任务与轨迹仍仅在正式 Run 时记录。25 通道可看 Roll 目标与实际、回收、Yaw 请求/分配、速度、质量和帧年龄；通道表见 [调参命令](调参命令.md)。当前未提供完整 Pitch 内环输出遥测，不能用 PC 派生通道补造。

| 提示 / 现象 | 核对位置 |
|---|---|
| IMU INIT FAILED / IMU LINK LOST | SPI、供电、初始化与链路 |
| IMU SAVE + REBOOT | 前向设置与启动坐标不同，保存 Zero 后静止重启 |
| IMU CALIB INVALID | 静止标定状态，静置重新上电核验 |
| ATTITUDE NOT READY / DIVERGED | 收敛/发散状态与原始传感器 |
| BLDC LINK LOST | UART3、驱动供电与回读 |
| ROLL / PITCH OVER PROTECT | 相对机械零点的角度和实际保护参数 |
| FLYWHEEL OVERSPEED | A/B 回读及软限速；区分差模与共模积累 |
| PID OUTPUT INVALID | 有限值、参数、PID 状态 |
| RUN BLOCKED / INVALID TEST | 模式互斥、IPM、视觉新鲜度，以及启动安全条件 |
| Run 已结束但轮子仍动 | 先查是否仍处于 Balance，再决定完全停车 |

菜单 Save 只检查模式停车；cfg 保存另要求轮速稳定与队列静默；IPM 自动保存也走独立前台路径，三者不能混为一套条件。软件检查、TASKING 编译链接、台架控制表现分别记录，本次文档更新没有完成后两项。
## 转弯压弯的验证

见 [压弯控制说明](../design/压弯控制说明.md)。依次检查 run CH7 压弯指令、CH2 合成目标、CH1 估计姿态并用地面视频验证实际内倾，最后比较同速度同路线的单轮 RPM 余量与 Yaw 裁剪。CH7 非零不能独自证明压弯有效；仅增大 Lean Max 对尚未碰到原限幅的工况没有作用。

## 2026-09-12 扩大视觉偏差范围后的对照操作

烧录后先沿用低速基线及现有 pixel_kp、曲率前馈和压弯参数，不同时增加增益。固定速度、同一路线比较外偏与出弯回中；确认 run CH14 能超过原约 14.49 pixel，并结合 CH8/9 目标与命令、CH10 机体系实测角速度、CH11/12 Yaw 分配、CH7 压弯、CH1/2 Roll 和 CH21 动量权限检查。CH14 超过旧限幅只证明误差信息恢复，不能单独证明循迹改善。

副作用是大偏差或错误边线可请求更强转向，增加回中超调、摆头及飞轮动量需求；更大的 Yaw 命令也会提高压弯请求。Yaw 总目标、斜率、Roll 合成角和电机输出限制仍生效，但不保证避免饱和。若明显恶化，先回退此编译常量到 5000 做同条件对照；10000 可作中间档，均需重新编译烧录。如果 CH8 已限幅、CH11/12 明显裁剪或 CH21 降低，继续扩大视觉范围不能解决执行余量不足。

2026-10-04 起姿态解算采用 A+ r10h：每次启动静止采集 6000 点（约 6 秒），再等待 3 秒成功更新；采用本车未标定的单位矩阵，故障须停机重新静止启动。首次调试须核验时序、轴向与动态延迟，详见 [A+ r10h 移植说明](../design/Aplus-r10h移植说明.md)。
