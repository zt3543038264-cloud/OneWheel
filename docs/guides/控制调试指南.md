# 后续控制调试路线

更新：2026-11-16。当前主轮测试暂停，整车尚未验收自主持续站立。

1. 恢复时完成主轮正反起转测量、编码器方向和飞轮反作用方向确认；完成手动保存、随后验证开机读取。
2. 主轮 Pitch：角速度内环 → 角度环 → 速度外环，逐环观察响应、振荡和饱和，不直接复制旧车参数。
3. 飞轮 Roll：保持当前控制方法调通，联合 Pitch，检查飞轮速度持续累积及饱和问题。
4. 验证脱手持续站立与小扰动恢复，再实现低速前后移动、停车和可控 Yaw。
5. 之后选择摄像头定位方案。先定义指定点是视觉标记还是地图坐标；安装摄像头后复核重心与振动。
6. 视觉/定位输出位置和朝向，导航生成速度/转向目标，平衡控制执行；接近目标减速，停止移动后继续保持平衡。

视觉与路径旧指南保留作为代码参考，不证明当前车辆已经具备导航功能。
