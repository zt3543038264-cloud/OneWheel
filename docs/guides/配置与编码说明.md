## WiFi

1. 在 `code/config.h` 设置 `STATION_WIFI_ENABLED`。`1` 使用 WiFi SPI；`0` 使用原 UART2，此时编译不需要私有配置文件。
2. 本机配置只填写 `STATION_WIFI_SSID`、`STATION_WIFI_PASSWORD`、`STATION_WIFI_PC_IP`。电脑 IP 应填写电脑在当前热点下的 IPv4，不是模块 IP，也不是 `0.0.0.0`。
3. 公共端口仅在 `config.h` 修改：电脑接收端口 `1349`，模块本地端口 `6666`。
4. 修改后重新编译、烧录并重启。仅修改源码或上位机设置不能改变车上已烧入的目标地址。

WiFi 分支会检查这三个本机宏是否定义，缺少定义直接报编译错误；模板中的空字符串需要用户实际填写。私有头采用包含路径查找，主机测试可注入测试配置，不读取或打印真实密码。

## 注释乱码

`code/` 和 `user/` 的源码是 UTF-8，原 ADS 工程却设置为 GBK。此次改为：

- 工程默认 UTF-8。
- 原 `libraries/` 目录继续使用 GBK。
- 库内已经采用 UTF-8 的文件逐个声明 UTF-8，避免另一批注释乱码。

设置保存在 `.settings/org.eclipse.core.resources.prefs`。若 ADS 已经打开旧编辑页，先保存自己的修改，再刷新工程并关闭、重新打开文件。不要在乱码显示状态下把源码另存为 GBK；源码文字无需转码。
