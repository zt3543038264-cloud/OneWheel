# 路径保存与惯性航向导航

实现日期：2026-09-15；航向闭环更新：2026-10-08。菜单入口：**主菜单 → Path**。

本功能把 C 轮编码器里程与现有 IMU 连续航向结合，完成相对路径示教、保存、显示和路径复现。没有桥、坡、跳跃、视觉接管等特殊段，也不要求摄像头或 IPM 就绪。原有视觉 Run 独立保留。

这属于轮式里程计与惯性航向融合的相对导航：没有绝对定位源，也没有加速度二次积分。Yaw 漂移、轮胎打滑、编码器比例误差会累积到位置估计中，菜单红色车位是估计值。

## 1. 车端操作

### 首次使用

1. 按现有流程完成静止 IMU 标定、姿态收敛、机械零点和三轴平衡验证。
2. 在 Params → Odometry 标定 `odom_counts_per_m`；向前推车时 C 轮计数必须增加。
3. 起初使用平整地面上的短直线和缓弯，Path 默认速度为 **0.20 m/s**，可在本页设置为 0.05～1.50 m/s。
4. 采集开始时以当时朝向建立路线坐标。复现前把车放在起点，朝向路线坐标的 +Y，选择 **Lock Start Heading** 锁定航向；以后同一路线重复发车保留该方向，摆车的小角度偏差会作为误差参与闭环。每次发车仍把当前位置视为 `(0,0)`，不会修正放错起点造成的位置偏差。
5. 未手动锁定时，第一次 Run Path 自动记住当前朝向；它不能知道第一次是否摆正。偏离已锁定方向超过 30° 时拒绝发车，提示 `ALIGN CAR TO LOCKED YAW`；应重新摆正，而不是靠原地转向。

### Path 页面

| 菜单项 | 操作与结果 |
|---|---|
| View Route | 查看完整路线、当前估计位置和选中的路径点 |
| New Push Record | 3 秒内两次确认后清除当前 RAM 路径并开始手推采集；不启动电机 |
| New Remote Teach | 3 秒内两次确认后通过 Balance 安全条件，启动 Remote 并建立新路径 |
| Finish Recording / Stop Teaching | 一次确认结束采集；补存至少 5 mm 的尾段；遥控示教同时完全停机 |
| Run Path | 有效路径至少 0.30 m，STOP 下两次确认后启动；运行或结束保持平衡时再次确认完全停机 |
| Speed | 确认进入编辑，上下以 0.05 m/s 调整，再确认退出；仅 STOP 可编辑 |
| Save Path | 把当前路径保存到独立 Flash；不保存 PID、IPM 或本页 Speed |
| Load Path | 两次确认后丢弃 RAM 修改，加载最新有效保存；没有有效记录时保留当前 RAM 路径 |
| Clear RAM Path | 两次确认清空 RAM；再按 Save Path 才会持久化删除 |
| Lock Start Heading | STOP、无 Test/Jog/导航且姿态就绪时，将当前朝向设为本路线 +Y；不启动电机 |
| Back / 返回键 | 结束采集或运行，并完全停机；返回主菜单 |

航向基准只保存在 RAM；普通停止、重复启动、保存路径和菜单返回不会清除它。新建采集、上传/加载路线、清空路线或重新上电会清除基准。锁定操作会更新路线会话版本，使之前的上位机启动授权失效；上位机应重新刷新路线后发车。现有 IMU 没有绝对航向来源，重启后必须重新对准锁定；长时间 Yaw 漂移仍需重新校正。

Speed 是本次上电的菜单设置，不增加全局参数 Schema；重新上电恢复 0.20 m/s。RAM 路径修改后显示 `RAM*`，保存或加载后显示 `SAVED`。参数菜单 Save/Reset 与路径保存相互独立。

### 手推采集

保持车身正常立姿，选择 New Push Record 后向前推车走完路线。暂停不会额外产生定时路径点；原地转向会更新航向，后续位移使用新的航向。结束后按 Finish Recording，再在停车条件满足后 Save Path。

采集只支持前进路线。允许不超过 0.15 m 的净回退以容纳平衡小幅往返；持续倒退超过该值会使本次采集失效，不能保存或运行，应重新采集。不要倒着拖回起点后再结束采集。

### 遥控示教

从 Path → New Remote Teach 发车，无需先到 Run Test 再启动。继续使用现有 UART2 命令，例如：

```text
speed:0,8
```

按 `raw/40` 换算，这请求向前 0.20 m/s。每条命令以 CR/LF 结束，应持续发送；超过 1000 ms 无有效命令，沿用 Remote 的零速、锁当前航向和保持平衡行为。

示教期间仅接受 0～1.50 m/s，即速度原始值 0～60；反向和超限请求被拒绝，普通 Remote 的原有范围不变。转向仍使用已有的相对航向命令及 `steer_dir`，采集记录实际测到的航向。按 Stop Teaching 或串口 `stop` 结束并完全停机，再保存路径。

达到 256 点时停止采集，保留已有前缀并显示 `FULL: PREFIX KEPT`；遥控示教同时撤销遥控权限、归零速度并保留平衡。需要再按返回键完全停机，不能继续依靠旧 Remote 会话行驶。

### 路线图

- 青色：保存/采集的路径折线；黄色线段：当前导航段。
- 绿色十字：起点；红色短线：估计位置与航向；黄色标记：选中的路径点。
- 上下键选择路径点，底部显示其序号和 X/Y 米坐标。
- 自动缩放以显示路线和估计位置；X 正方向向右，Y 正方向向上。
- **确认键**返回 Path 控制页，保留当前采集或运行；**返回键**停止采集/运行，再回到 Path 页。
- 图形在 CPU0 前台约每 250 ms 刷新，实际刷新受屏幕传输时间影响；不在控制中断绘图。

## 2. 算法与控制接入

### 路径采集

`path_nav.c` 在每次 5 ms 编码器更新后获取有符号位移增量。令本拍与上拍连续航向的中值减去采集起始航向为 `ψ`：

```text
x += Δs × sin(ψ)
y += Δs × cos(ψ)
```

不重写原始编码器计数。每个点包含 `x, y, s`，其中 `s` 为路径折线累计长度，第 0 点是原点。

- 距上个点约 0.20 m 时采点。
- 转向相对上段方向达到 5°，且距上点至少 0.05 m 时加密采点。
- 结束时补存至少 0.005 m 的剩余位移。
- 最多 256 点，直线约可覆盖 51 m；弯道加密会减少可覆盖长度。不是固定长度保证。

只在明确的“新建”操作中替换 RAM 路径，普通启动、停车、菜单翻页不会清除已有路线。

### 自动复现

运行以当前起点和锁定航向建立相对坐标；初始相对 Yaw 保留实际偏角，并选取最接近当前连续 Yaw 的等价基准，避免跨 360° 绕转。每 5 ms 更新位置，每 20 ms：

1. 在当前段及其顺序后继段上投影位置，更新单调递增的路径进度；不在全图寻找最近点，防止交叉路线跳到另一段。
2. 取前方 `0.30 + 0.35 × |实测速度|` m 的路径点作为转向目标。
3. 根据前瞻点计算几何航向，将它转换为最短角差对应的连续 Yaw 目标，并按 45°/s × 动量权限限制目标变化。目标始终指向路线几何方向，不再积分航向误差来生成不断漂移的目标；不额外乘遥控 `steer_dir`。
4. 根据预计算的弯道/制动速度包络、转向误差、飞轮共模动量权限和剩余距离规划速度；速度进入现有 Pitch 速度→角度→角速度串级。
5. 在现有角度更新拍执行 Path 专用 P 角度闭环：目标角减实测角，乘 `PATH_YAW_ANGLE_KP=3 s⁻¹`，得到角速度目标，不累积角度积分。角速度指令每 1 ms 按 180°/s² 平滑，限幅后进入原有 Yaw 角速度 PID。此专用角度增益不使用菜单的 Yaw Angle PID；其他模式沿用原参数。
6. 导航运动期间，前进速度 ≤0.03 m/s 时不主动追角，只保留陀螺阻尼；0.03～0.20 m/s 逐渐开放转向能力。沿前进过程纠正发车偏角，不先原地旋转。Yaw 内环使用本拍 Roll 混控剩余输出空间并抗积分饱和。
7. 压弯使用实际平滑后的角速度指令，保留原速度淡入、变化率限制、Roll 合成角限制和 Roll 优先混控。

启动前在 CPU0 前台计算整条路线的速度包络。按相邻线段夹角估计曲率，弯道使用 0.50 m/s² 横向加速度与 35°/s 转向能力预算中的较小限速，再以 0.40 m/s² 减速预算向前传播制动约束；规划时另留约 0.15 s 行程余量。终点仍执行原有制动状态机。这些是规划预算，不是实测硬件极限。

每次规划最多推进 8 个当前段、24 个前瞻段；没有全路径搜索、动态分配、Flash 或格式化操作进入中断。

编译期约束：

| 项目 | 值 |
|---|---:|
| 巡航速度 | 菜单设置，默认 0.20、最大 1.50 m/s |
| 速度斜坡 | 加速 0.25、减速 0.50 m/s² |
| Path 航向角闭环增益 | 3 s⁻¹，P-only，无角度积分 |
| 转向率上限 | 45°/s，再乘动量权限 |
| 转向率变化上限 | 180°/s² |
| 发车允许偏离锁定基准 | 最大 ±30°，超出拒绝启动 |
| 前瞻方向误差超过 100° | 路径错误并停止，不原地找方向 |
| 估计位置距当前段超过 0.60 m | 路径错误，公共安全停机 |
| 8 s 未增加至少约 2 cm 进度 | 路径错误，公共安全停机 |
| 单拍位移超过 5 cm / 航向跳变超过 10° / 非有限值 | 输入异常，退出 |

进入末端时同时要求剩余进度与估计终点距离小于 0.06 m，随后进入制动，速度目标为零并保持终点附近航向。速度低于 0.04 m/s 持续约 300 ms 后显示 DONE，**继续三轴平衡**。制动 5 s 仍未完成则退出并完全停机。

普通终点并非精确位置伺服：停车误差受到前瞻、速度闭环、里程与姿态误差影响。上述阈值是当前实现参数，不是已经实测的车辆性能。

## 3. Flash 与参数互斥

- DFlash 逻辑页 **9、10** 为同一条路线的 A/B 冗余记录，**11** 仍由原参数/IPM 使用。
- 每份记录有 magic、格式版本、递增代数、点数、点数据、CRC32。
- 保存时擦写较旧/无效的槽，逐字回读比对；原最新槽保留。
- 启动和 Load 选择 CRC、长度、有限值、累计长度和几何关系均有效的最新记录；新槽损坏可回退旧槽。
- 保存空路线会写入较新代数的空记录，避免下次启动重新加载旧路线。
- 路径缓存和保存/回读缓冲在 CPU0 DSRAM，长数组不放中断栈。
- 手动 Save/Load 要求 STOP、没有 Test/Jog/采集/导航、驱动在线且 A/B 速度绝对值不超过 50 RPM、C 轮无计数，连续约 500 ms；同时 UART2 接收空闲至少 100 ms、无待处理 cfg 保存、无待存 IPM。
- 采集、导航以及导航结束后保持 Balance 时，cfg 参数写权限为零；菜单参数编辑也禁止。可继续读 Schema、状态和遥测。完全停止后恢复原有权限。
- IPM 自动保存会等待路径采集结束。新建或运行路径不会修改 PID、里程标定或其他运行参数。

两个槽只保存一条当前路线及上一份有效副本，不是两个可选路线库。重新利用 DFlash 页 9/10 前需保留此分配，不能与其他持久化功能重叠。

现有 `run:` 25 通道帧的 CH24 **bit7** 表示 Path 控制模式仍激活，包含终点 Balance 保持；bit0 继续只代表视觉 Run。Path 下 CH8 为航向角闭环产生的限幅角速度目标，CH9 为实际平滑下发的角速度指令，CH18 提供导航规划速度，其他控制反馈仍按原定义。视觉专属通道不代表导航输入。

## 5. 上位机直接设计与执行

1. 打开上位机“路线与惯导”，生成直线，或勾选地图点击添加航点；也可编辑 X/Y 表格。
2. 按“按航点生成路线”查看青色预览，选择执行速度上限。
3. 连接新版车端，STOP 下上传到 RAM，等到黄色车内路线及确认提示出现。上传不会自动行驶。
4. 需要掉电保留时点“保存车内路线到 Flash”；本地 JSON 文件可保存多条路线。
5. 把车放在起点并朝向图中 +Y，在车端 Path → Lock Start Heading 锁定；刷新上位机车内路线后，点“执行已核对的车内路线”，核对长度与速度后确认。已有锁定基准的重复发车不需要重新锁定。
6. 完成后车辆保持平衡；完全停机使用顶部“立即停车”、空格键或车身返回键。

从 Flash 载入或车身修改路线后，先下载核对再启动。路线自主执行不依赖上位机持续发送速度，串口断开后仍按车端路线运行；停车命令需要链路可用，现场可用车身返回键停机。
