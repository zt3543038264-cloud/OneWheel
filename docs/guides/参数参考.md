# 参数参考

核对日期：2026-10-08（角度外环参数周期适配；沿用已有 IMU 前向及机械零点迁移）。下表从 [param.c](../../code/Common/param.c) 的 g_param_table、param_load_defaults()、[config.h](../../code/config.h) 和 [menu.c](../../code/Menu/menu.c) 提取，共 75 项。

默认值来自 2026-09-21 17:53 实车完整 Schema 的 75 项参数，已由用户确认，并转换成当前实车为正向基准的表示。精确原始值、转换因子和新默认值见 [默认值快照](../../tools/unicycle_station/docs/defaults-20260921.json)。有效旧 Flash 自动迁移，仍优先于编译默认值。机械零点/IPM 保留有符号几何意义；未启用的增益仍为 0。参数范围仍允许反向试验，正值是当前默认基准，并非强制绝对值。分组按 cfg_group()，步长为车身菜单步长；Schema 的通用步长为 float 0.0001/int 1。

所有值修改进入 RAM；保存规则见 [菜单指南](菜单指南.md)，完整串口权限见 [协议](../../tools/unicycle_station/docs/protocol.md)。PID 只有当前启用环在运行时可写，Motor/Zero/IPM 被 Schema 标记为危险参数；Balance 基础状态允许 Run/Lean 共 14 项速度、转向、压弯参数在线写入，需 Schema bit4 与 stat 权限 bit24 确认；其他非 PID 的 cfg 写入要求 STOP。极性字段只允许 ±1，不能把表中数值区间理解成允许 0。

角度外环参数说明（2026-10-08）：`r/p/y_angle_kp/ki/kd` 均保留原 5 ms 基准。当前 1 kHz（1 ms）固件内部自动使用 Kp 原值、Ki×0.2、Kd×5，积分累计限幅×5；这里的默认值、范围、菜单步长与 Flash 值继续沿用原值，无需用户重复换算。角速度、速度和回收环参数不使用此适配。

## 名称、量纲与编译常量

- Run speed、zebra_stop_offset_m、odom_test_speed 分别用 m/s、m、m/s；run_accel/decel_mps2 用 m/s²。
- odom_counts_per_m 是 counts/m；Pitch 速度环内部使用 counts/20ms，换算关系为 speed_mps × counts_per_m × 0.020。
- direction_rate_kd 对应结构字段 direction_balance_kd；roll_protect/pitch_protect 对应 *_protect_angle。串口与保存使用表中参数名。
- fly_speed_limit 单位 RPM，0 表示关闭软超速；fly_slew 单位 duty/1ms，0 表示不限制变化量。
- r_angle_limit、r_rcy_limit、r_rcy_tau、road_wide_near/far、err_offset、track_err_gain、track_base_speed、speed_up_rate/down_rate 和旧元素速度倍率均不在当前 Schema 中。
- 环岛/元素时间、提边阈值、Yaw rate/超前角限幅、Roll 合成目标限幅、Pitch 速度环限幅等是 config.h 编译常量，不是可通过 cfg:set 修改的参数。
- IPM 默认矩阵适用于当前源码基线；矩阵可逆或被算法接受不等于安装几何已经重新标定。

## 方向基准（2026-09-21）

六个方向参数默认全部 +1，表示当前已调好的实车方向；-1 表示相对反转。实际硬件符号由 `config.h` 与参数相乘：A/B +1，C 电机/C 编码器/IMU/转向 -1。

`steer_dir`（Steer Dir）同时控制视觉道路偏差与遥控转向输入转换成目标 Yaw 的符号。+1 保持当前已确认的纠偏方向；-1 会反向纠偏。它不修改 IMU 测量值或电机接线极性，也不是转向力度参数。实际 Remote 目标是当前 Yaw + `STEER_DIR_BASE × steer_dir × turn`。

Roll Rate 界面默认 20/0/8，内部仍为 +20/0/-8；Yaw Rate 界面 56/0/0，内部为 -56/0/0。Pitch 及其他环不反号。正数表示对应项当前作用方向，不能把 Roll 三项统一反号。说明见 [方向基准整理](../design/方向基准整理.md)。
