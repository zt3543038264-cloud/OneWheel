# 主轮正反方向起转记录

更新：2026-11-16。当前测试暂停，尚无可靠的两方向起转数值。

旧文档的 Mode8、`debug_ground_pwm`、固定 1800/3200 和旧 Flash 结论不再作为当前操作依据。

恢复测试时使用 **Params → Motor → C Raw + HOLD / C Raw - HOLD**；幅值为 `Duty Drv`。
此入口不加方向或死区补偿，正负代表原始输出符号，实际前后需观察。
主轮悬空并固定车身，先零幅值；记录各方向首次持续转动值和减小时停止值。
换向前先 `C Raw STOP` 并等轮子停稳。有声不转时不长时间维持堵转。

| 条件 | Raw 正向 | Raw 负向 |
|---|---|---|
| 物理转向 | 待测 | 待测 |
| 编码器符号 | 待测 | 待测 |
| 首次持续起转幅值 | 待测 | 待测 |
| 降幅后的停转幅值 | 待测 | 待测 |

同时记录电机动力电压和悬空/接地条件；悬空起转值不能直接视为接地负载下最终补偿量。
完成执行器标定后再调整闭环补偿，不将零速一律归因于死区。
