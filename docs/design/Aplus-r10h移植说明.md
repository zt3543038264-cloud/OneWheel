# A+ r10h 独轮车移植说明

移植日期：2026-10-04。来源为用户指定的 `660RB_Aplus_r10h_Portable`。已阅读原包 README、来源与修改说明、离线验证说明及 TC264 接入参考。本次默认使用推荐 A+，保留 B 对照和 C 辅助状态；原云台验收结论不作为独轮车验证结论。

## 接入位置与周期

| 文件 | 作用 |
|---|---|
| `code/Estimation/Attitude/r10h/` | 六个编译入口及全部数学依赖；候选数学文件保持原始字节 |
| `code/Estimation/Attitude/attitude.c` | 原公开姿态/安全接口的 A+ 适配层 |
| `code/HW_Drivers/IMU/imu.c` | 6000 点启动均值、既有车体系方向和控制用角速度 |
| `imu_r10h.inc`、`imu_spi.inc` | 单次六轴采样与运行时 SPI 超时保护，只由 imu.c 包含 |
| `control.c` | 在现有 1 ms 采样后调用 `attitude_tick1ms()` |
| `Lcf_Tasking_Tricore_Tc.lsl` | CPU0 中断栈增加至 4 KiB；其它核栈不变 |

数学核心固定每 1 ms 更新一次。2026-10-08 起，Roll/Pitch/Yaw 每 1 ms 发布给 1 kHz 角度外环，CPU1 反馈仍为 5 ms；角速度内环仍使用每 1 ms 的启动零偏已扣除、未经过 A+ 滤波的体坐标 p/q/r。Pitch 欧拉角速度投影继续用 `gyro_y*cos(roll)-gyro_z*sin(roll)`，Roll 缓存正常每 1 ms 更新。编码器/Path/压弯保持 5 ms，速度/回收/方向保持 20 ms。菜单与 Flash 的角度参数沿用原 5 ms 基准，固件自动换算；详见 [1 kHz 试验说明](角度外环1kHz试验说明.md)。

初始化、更新和 A/B/C 输出检查均由 CPU0 独占。初始化在控制定时器启动前，更新和复制在同一控制中断；CPU1 继续通过原有带内存屏障的反馈交换接口读取姿态。新增可变状态在 `cpu0_dsram`。没有在 ISR 增加字符串格式化、Flash、动态内存或批量补调用。

## 输入单位、轴向与标定

原始传感器物理量为 gyro °/s、acc g。两者都使用原映射 `body=(forward*sy, forward*sz, sx)`，保持同一右手系和启动方向锁存。默认有效 forward=-1，菜单 `imu_forward_dir=+1` 的当前车辆语义、机械零点联合保存及重启闸保持原逻辑。

两条输入用途分开：`imu_get_raw_sample()` 给 A+ 的是未经启动零偏扣除、未经比例矩阵和外部滤波的车体系六轴；`imu.gyro_*` 给原控制器的是扣除启动平均零偏的角速度。A+ 接口内部扣均值一次，核心随后乘矩阵及学习在线零偏。外层不重复扣零偏，也不为了 Mahony 再整体反转加计。

原样品约 1.009～1.011 的矩阵不能直接用于本车；此处按来源说明改用单位矩阵，保留两项验收路径选择宏。单位矩阵是未标定起点，不代表本车达到原云台报告精度。后续针对本车传感器做比例/交叉轴标定；如果从传感器坐标移入矩阵，需变换为 `R M R^T`，前向变化时同样要适配矩阵。启动平均零偏不替代比例标定。

## 驱动和开机流程

保留本车 SPI 实例、引脚和完整逐飞初始化（BDU、自增、滤波等）；CTRL1_XL/CTRL2_G 均设为 `0x8c`，匹配 ±8g / ±2000°/s、两轴输出率 1667 Hz。转换系数同步为 4098 counts/g 和 14.3 counts/(°/s)，校验身份、量程/ODR 寄存器及 BDU/自增位。没有复制测试工程的 SPI3 引脚，也没有保留本车旧 416 Hz 加计与额外滤波覆盖。

上电固定车身，静止采集 6000 个有效六轴样本，约 6 秒；期间控制定时器尚未启动。保留陀螺/加计峰峰值运动检查，额外要求均值重力模长在 0.75～1.25g；晃动可重新采集，最多三次。总线/原始样本故障立即中止标定。A+ 从均值重力对齐，然后仍需 3000 个连续成功的 1 ms 更新才放开原收敛启动闸。因此正常开机约 6 秒静止采样加 3 秒更新等待；不是 0.6 秒标定。

## 异常保护与诊断

每拍确认 acc/gyro 数据就绪，随后一次读取连续的 12 字节。检查全 0/0xFF、加计全 0、量程端点饱和和非有限物理量，每 100 个样本复查 WHO_AM_I。单独三轴 gyro 为 0 可能是正常静止，不再作为断链的充分依据。任何无效/丢失样本锁存 `imu_link_lost()`，不再融合或发布旧结果，不自动恢复。

IMU 专用 SPI 接收片段为每笔事务设共享 100 μs STM 截止时间；RX FIFO 与结束标志等待均受它约束。失败释放 CS 并锁存断链，维持现有控制停机分支。没有改公共逐飞 SPI 驱动；开机的完整逐飞初始化及配置写仍使用其原 API，在控制定时器启用之前完成。

更新间隔用 STM 无符号差监测，允许 750～1250 μs；越界锁存姿态故障。A/B/C 的 fault 和角度/诊断值都做有效性检查；A+ 本拍拒绝输出时不发布旧姿态。单次姿态更新耗时达到 1000 μs 也锁存故障。故障后须停止、重新上电并静止标定，不能丢帧后快速补算。原角度、驱动、过速和模式互斥保护继续生效。

`att_diag.period_us/update_us/max_update_us` 可在调试器查看；它们不增加 UART2 字段或 Flash 参数。`acc_weight` 是修正权重，`is_static` 是内部零偏学习判定，不是电机许可；`bias_z` 仍以 rad/s 表示在线体坐标 Z 零偏，不含启动均值，不等于完整航向漂移率。

首轮链接调用树对 1 ms 控制路径给出 2088 字节的保守估计（包括间接时钟调用的估计），超过原 1024 字节。CPU0 中断栈改为 4096 字节，偏移由原公式重新计算；需在本车调试时实测高水位和最坏 ISR 时长。编译通过不能替代这两个硬件验证。

## 验证与上车顺序

可运行 `python tools/attitude_r10h/run_tests.py`，只编译本车真实 IMU/姿态适配层与六个核心文件，SPI/STM 用模拟接口，不操作硬件。覆盖 API 旧输出拒绝语义、0.1/0.5/90°/s 连续航向、慢速倾转、倾斜初始化、强振动零偏判定、6000 点均值、双向映射、单次扣偏、1 ms 解算/1 ms 发布、STM 回绕、调度早到/丢拍/超时、坏身份、坏帧/饱和和运动标定拒绝。来自原包的回归输入已适配单位矩阵；具体输出在 `tools/attitude_r10h/host_results.json`。模拟测试同时编译执行目标 SPI 等待实现，覆盖每个 RX 等待点、结束等待、100 μs 截止时间、CS 释放及 STM 回绕；真实总线耗时和异常电气条件仍须实测。

固件通过仓库的 `python tools/ads/build.py` 进行真实 ADS/TASKING 编译链接；2026-10-04 移植构建记录见 `tools/attitude_r10h/build_result.json`；2026-10-08 的 1 kHz 构建记录见 `tools/attitude_r10h/build_result_1000hz.json`。本次未烧录、未做电机架空/云台或路测。移植前源文件快照及哈希保存在 `tools/attitude_r10h/pre_migration_20261004/`，ADS 不编译 tools 下的快照。

首次上车：先保持输出停止，完成开机静止采样并确认无异常；检查平放 |acc|≈1g、各轴转动正负方向和 Roll/Pitch 零点；检查连续航向跨 ±180°以及 Pitch 投影；观察 1 ms 最坏时长、栈余量和断开传感器时的停机；再比较静止漂移、慢转、快速往返、倾斜开机、振动保持和多姿态切换，最后做架空低输出单轴与平衡测试。控制增益和原机械零点未自动重调，需要实车核验动态延迟后决定。六轴仍没有绝对航向参考，不能承诺长期 yaw 无漂移。
