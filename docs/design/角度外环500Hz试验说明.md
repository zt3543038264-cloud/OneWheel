# 角度外环 500 Hz 试验说明

此文保留 500 Hz 版本的历史实现与验证记录。用户反馈该版表现可以，随后要求提高到 1 kHz；当前实现见 [1 kHz 试验说明](角度外环1kHz试验说明.md)。构建缓存产物会被后续构建替换，保留的 500 Hz HEX 位于 `.ads/firmware_trials/500hz/`。

2026-10-08：Roll、Pitch、Yaw 三个角度外环由 5 ms（200 Hz）改为 2 ms（500 Hz）。姿态角发布与角度环共用 CPU0 中断中的同一分频标志，正式 Balance/Run/Remote/Path 和单轴 Angle/Speed 测试都使用这个节拍，避免测试启动相位导致角度环读取上一拍姿态。

## 参数匹配

本工程位置式 PID 使用误差直接累加和相邻误差差分，没有显式 dt。菜单、Flash、cfg 和上位机中的角度参数保留原 5 ms 基准，固件在初始化与在线刷新时自动转换：

| 项目 | 2 ms 内部值 | 原因 |
|---|---|---|
| Kp | 原值 | 比例作用不依赖周期 |
| Ki | 原值×0.4 | 每秒计算次数变为 2.5 倍 |
| Kd | 原值×2.5 | 连续变化的相邻误差差值缩小 |
| 积分累计限幅 | 原值×2.5 | 保持 Ki×积分限幅的输出上限 |

现有 Flash、菜单和上位机参数可以直接使用，无需手动换算或重新保存。增益符号保持原有规则。默认三个角度环均为纯 P，因此默认 Kp 数值不变；Flash 中非零 I、D 也会自动适配。在线刷新不清积分或误差历史，启停仍沿用原复位流程。参数表、Flash 版本、通信字段和保存权限保持兼容。

周期换算保持积分和微分的时间尺度；目标阶跃、采样噪声、限幅及闭环响应仍可能变化，特别是非零 D 对高频噪声的响应需要观察。

## 保留的节拍

| 周期 | 功能 |
|---|---|
| 1 ms | 六轴读取、A+ r10h 核心、角速度反馈及内环、保护、输出和有界 UART 搬运 |
| 2 ms | 欧拉角/连续航向发布、三个角度外环；Roll 变化时更新 Pitch 投影缓存 |
| 5 ms | C 编码器、Path 位姿/采点、CPU1 反馈；活动串级中的压弯 |
| 10 ms | 按键扫描 |
| 20 ms | Pitch 速度、Roll 回收、方向控制、速度规划和 Path 前瞻规划 |

压弯的 0.005 s 时间步长与低通系数保留。速度/回收环使用原参数，角速度内环的符号和参数不参与角度环换算。

## 验证与试验

主机回归执行实际 PID、周期适配和控制中断函数，检查同一物理时间内的积分、线性斜坡微分、积分限幅、在线参数刷新、原内环符号及 1/2/5/10 ms 调度和发布顺序。A+ 回归继续检查真实姿态适配层的 1 ms 解算/2 ms 发布、标定、故障和有界 SPI 等待。主机测试不模拟车辆动力学。

当前 ADS 构建结果见 [500 Hz 构建记录](../../tools/attitude_r10h/build_result_500hz.json)。新产物的实际路径及哈希记录在该文件中；仓库原 Debug 目录不是这次构建的产物。本次未烧录或进行实车试验。

对照时保持同一组公开参数、零点和负载，先完成启动静止标定，再架空观察单轴 Angle/Speed 测试的振荡、噪声和输出限幅，随后进行低速平衡对照。比较 Roll/Pitch 跟踪、超调、恢复时间、Yaw 抖动以及调试器中最坏 ISR 时长和栈余量。现有遥测频率足以看整体响应，高频抖动和中断峰值仍需目标机测量。提高更新率有望减少采样保持延迟，实际效果由这些对照结果判断。
