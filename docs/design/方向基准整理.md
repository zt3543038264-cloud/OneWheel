|---|---:|---:|---|
| Dir A / Dir B | +1 / +1 | +1 / +1 | 输出与 RPM 回读不变 |

所有方向项的 **+1 表示当前已调好的基准，-1 表示相对反转**。固定转换放在 `code/Common/direction_config.h`，运行映射放在 `code/Common/param.h`，同时覆盖初始化和运行期增益刷新。Roll P/D 原本符号相反，必须分别处理，不能翻转整个 Roll 环；Yaw Rate 则统一转换三个系数，包括以后启用的 I/D。

其他参数按最新回读固化：Pitch 速度环 0.06/0.002/0，角度环 8.999999/0/0，角速度环 20/0.6400001/0。所有非零 PID 默认增益为正，未启用项保留 0。Roll/Pitch 机械零点 -0.6°/-2.999999°，以及 IPM 中的负系数保留，因为这些是有符号几何量，取绝对值会改变实际平衡位置或投影。

完整原值、转换因子、新默认值及日志来源哈希见 [75 项快照](../../tools/unicycle_station/docs/defaults-20260921.json)。

## Steer Dir 是什么

它决定“道路偏向哪边/遥控要求向哪边”与“目标 Yaw 朝哪边改变”的对应关系。当前正常使用 +1；-1 把视觉和遥控转向请求反向。它不是转向力度、Yaw 陀螺仪方向或电机接线方向。

- 视觉：同时作用于像素偏差、航向偏差、曲率前馈的符号，后续送入 Yaw 控制。
- 遥控：`目标 Yaw = 当前 Yaw + STEER_DIR_BASE × steer_dir × turn`，本车 `STEER_DIR_BASE=-1`。
- 修改转向力度应调整方向反馈/前馈和相应 Yaw 参数；不能靠切换 Steer Dir 加强转弯。

压弯仍由原有转向指令和速度计算；这次没有改变压弯公式、Yaw 混控、轮速比例、PID 周期或输出限幅。

## FOC 边界

用户确认 A/B 动量轮外置驱动板已采用磁编码器 + FOC，沿用原 UART 接口。TC264 继续发送原有符号与量纲的双路驱动指令并接收 RPM；本仓库没有新增 FOC 电流环或磁编码器采集算法。不能据此将现有 duty 指令宣称为已标定的电流/力矩指令。C 轮现有 PWM/DIR 与脉冲/方向编码器接口保持原配置。

## 升级与保存

1. 烧录本次编译的固件后静止启动，连接上位机重新获取完整 Schema。hello 标识应为 `tc264-cfg1-task1-sign2`，cfg 协议仍为 1。
2. 不必 Reset 或擦参数。旧 Flash 保留既有实车设置，并自动转换到新表示。检查六个方向是否与上述已确认基准一致；若旧 Flash 的数值不同，迁移会保留它原本的实际作用，不强制改成新默认。
3. 架空短时核对 C 输出及轮速方向、手动倾斜核对姿态，然后低输出验证。确认后在 Params 页 Save 保存全部参数。
4. 当前前向使用 IMU Fwd=+1，无需再次置反。以后主动改变它仍会联动翻转两个机械零点，并要求保存 Zero、静止重启。

Flash 新魔数 `0x51435453` 用于区分归一化语义；旧 `0x51435452` 在 CRC 校验后转换，读取不写 Flash，分组保存也迁移未改动组，防止重复转换。更老的无 IMU 方向记录继续按旧前向迁移零点。映射可逆，不使用绝对值，因此旧版已有的相对反向设定仍然保留。

旧上位机工作区/预设保存的是旧数值，不会因为升级 MCU 自动转换；请使用本次更新的 Profile/默认工作区并重新回读，不要直接重新下发旧预设。旧固件也不识别新 Flash 魔数，降级需要恢复旧版参数备份。上位机已更新源码和配置，尚未重新打包桌面 EXE。
