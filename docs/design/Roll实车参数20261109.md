# Roll实车参数记录（2026-11-09）

来源：用户提供的Roll菜单照片。用户指定提交说明为`角速度环改为增量式，参数稳定直立`。稳定直立是用户的实车反馈；本次执行的是参数固化、代码检查、主机回归和ADS编译，没有远程复现实车表现。

| 菜单参数 | 编译默认值 | 配置宏 |
|---|---:|---|
| Rate Kp | 45.00 | R_RATE_KP_DEFAULT |
| Rate Ki | 0.050 | R_RATE_KI_DEFAULT |
| Angle Kp | 30.00 | R_ANGLE_KP_DEFAULT |
| Angle Ki | 0.000 | R_ANGLE_KI_DEFAULT |
| Angle Kd | 20.00 | R_ANGLE_KD_DEFAULT |
| Speed Kp | 0.0001 | R_RCY_KP_DEFAULT |
| Speed Ki | 0.0000 | R_RCY_KI_DEFAULT |
| Speed Kd | 0.0000 | R_RCY_KD_DEFAULT |

| Notch Q | 3.0 | R_RATE_NOTCH_Q_DEFAULT |
| Notch dB | 0 | R_RATE_NOTCH_DB_DEFAULT |

配置位置：`code/config.h`。Roll Rate为1ms增量式PI，Rate KD保持停用。Angle为1ms位置式PID，菜单参数仍按5ms参考值换算，照片中的Angle KD=20直接写入菜单默认宏，不预先乘5。Speed为20ms位置式PID。Notch dB=0时完全旁路，45Hz和Q=3只是保留的设置值，不表示陷波正在生效。

本轮只从照片更新上述Roll参数，不推测未显示的机械零点、地轮参数、左右电机/编码器极性，也不修改私有WiFi配置。旧Flash中的有效保存值仍优先于编译默认值；写入config并不会自动覆盖板上的旧调参记录。需要使用默认值时，按项目现有菜单操作，先记录需要保留的其他实车参数。

同步更新仓库内上位机profile与默认工作空间中的Roll默认值、三项Rate陷波参数说明。当前Mock参数集合补齐为80项，与固件参数名称集合一致；这不是对全部历史实车快照的重写。

软件回归核对实际`param_init()`/`param_load_defaults()`输出与照片一致，并确认有效Flash仍能覆盖默认值；另包含先前增量PI、限幅/复位、方向、Motor页保存及双格式UART测试。最终构建结果和产物SHA256见`.ads/build/latest.json`。本轮没有烧录主控或驱动板。
