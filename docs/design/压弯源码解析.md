# 压弯源码解析

压弯是在转弯时给 **Roll 角度目标**加一个随车速和转弯指令变化的偏移。Yaw 负责让车转向，Roll 闭环负责让车身跟上侧倾目标。这里的压弯角是前馈计算结果。

## 1. 调度入口

源码见 [control.c:1182](../../code/Controller/control.c#L1182)。

```c
    if (run20) direction_control_update();
    direction_yaw_rate_update();
    if (run5) g_lean_offset = lean_offset_update();
    if (run20) speed_ramp_update();                      // 速度目标斜坡与速度环同拍
    g_pwm_roll  = roll_cascade_ctrl(g_roll_zero + LEAN_DIR * g_lean_offset, run_angle, run20);
```

- 方向控制按 20 ms 更新，随后更新斜率限制后的转弯率指令。视觉 Run 使用 `s_direction_yaw_rate_cmd`，Path 使用 `s_path_yaw_rate_cmd`。
- 压弯每 5 ms 更新一次。串级用最近一次压弯结果计算 Roll 目标，角度环和角速度环按 1 ms 运行。
- 实际车速来自 C 轮编码器的 `Y_Motor_GetSpeedMps()`，保留前进、倒车符号。转弯率用目标指令，因此指令发出后便能开始生成侧倾目标。

## 2. 压弯生成

源码见 [control.c:783](../../code/Controller/control.c#L783)。

```c
static float lean_offset_update(void)
{
    float target = 0.0f;
    float speed = Y_Motor_GetSpeedMps();
    float rate = s_direction_yaw_rate_cmd;
    uint8 path_turn = (uint8)(s_path_active && path_nav_running());
    float limit = ctrl_is_finite(LEAN_MAX_ANGLE) ?
                  constrain_float(LEAN_MAX_ANGLE, 0.0f, DIRECTION_LEAN_LIMIT) : 0.0f;
    float slew = ctrl_is_finite(LEAN_SLEW_DPS) ?
                 constrain_float(LEAN_SLEW_DPS, LEAN_SLEW_DPS_MIN, LEAN_SLEW_DPS_MAX) :
                 LEAN_SLEW_DPS_DEFAULT;
    float step = slew * LEAN_DT_S;
    float delta;

    if (!ctrl_is_finite(g_lean_offset)) g_lean_offset = 0.0f;
    if (!ctrl_is_finite(s_lean_speed_mps)) s_lean_speed_mps = 0.0f;
    g_lean_offset = constrain_float(g_lean_offset, -DIRECTION_LEAN_LIMIT, DIRECTION_LEAN_LIMIT);

    if (path_turn) rate = s_path_yaw_rate_cmd;
    if (((s_run_active && s_run_vision_armed && g_track_valid && g_vision_ipm_ok &&
        g_vision_age_ms < VISION_LINK_TIMEOUT_MS &&
        s_direction_last_mode != TRACK_MODE_HOLD) || path_turn) &&
        ctrl_is_finite(speed) && ctrl_is_finite(rate) &&
        ctrl_is_finite(LEAN_TURN_KP) && ctrl_is_finite(LEAN_SPEED_KP))
    {
        float speed_abs;
        float fade;
        float signed_fade;
        float rate_abs;

        speed = constrain_float(speed, -RUN_SPEED_MAX_MPS, RUN_SPEED_MAX_MPS);
        s_lean_speed_mps += LEAN_SPEED_FILTER_ALPHA * (speed - s_lean_speed_mps);
        speed_abs = fabsf(s_lean_speed_mps);
        fade = constrain_float((speed_abs - LEAN_SPEED_MIN_MPS) /
                               (LEAN_SPEED_FULL_MPS - LEAN_SPEED_MIN_MPS), 0.0f, 1.0f);
        signed_fade = (s_lean_speed_mps < 0.0f) ? -fade : fade;
        rate = constrain_float(rate, -DIRECTION_YAW_RATE_LIMIT, DIRECTION_YAW_RATE_LIMIT);
        rate_abs = fabsf(rate) - LEAN_RATE_DEAD_DPS;
        if (rate_abs > 0.0f)
        {
            rate = (rate < 0.0f) ? -rate_abs : rate_abs;
            // 小角度 phi[deg]≈v[m/s]*r[deg/s]/g；限10°内无需在ISR求atan。
            // K1方向项也按车速淡入；直行(rate=0)绝不产生速度独立的侧倾。
            target = signed_fade * rate *
                     (constrain_float(LEAN_TURN_KP, 0.0f, LEAN_TURN_KP_MAX) +
                      constrain_float(LEAN_SPEED_KP, 0.0f, LEAN_SPEED_KP_MAX) *
                      speed_abs / LEAN_GRAVITY_MPS2);
            target = constrain_float(target, -limit, limit);
        }
    }
    else
    {
        s_lean_speed_mps = 0.0f;
    }

    delta = target - g_lean_offset;
    if (delta > step)  return g_lean_offset + step;
    if (delta < -step) return g_lean_offset - step;
    return target;
}
```

1. **启用条件。** 视觉 Run 要同时满足运行已启动、本次视觉已握手、目标有效、IPM 有效、视觉年龄小于 100 ms、方向状态非 HOLD。活动的 Path 导航可独立通过模式判断。两条路径都要求车速、转弯率和两个增益为有限值。单独 Balance、Remote 和单轴测试没有主动压弯来源。Beacon Run 也要满足上述视觉条件，因此仅有有效信标、没有有效 IPM 时不会生成压弯。
2. **车速低通和淡入。** 以 0.10 的系数更新带符号速度，时间常数约 47 ms。速度绝对值在 0.05 m/s 及以下时权重为 0，从 0.05 到 0.30 m/s 线性升至 1。倒车时给权重加负号，因此相同转弯率指令下压弯反向。
3. **转弯率连续死区。** 指令先限幅，再取绝对值减 2°/s。小于等于 2°/s 时目标为零。超出时恢复原符号，例如 +10°/s 进入公式的是 +8°/s。
4. **两项前馈。** 将带符号速度权重乘以 `Turn Kp × 有效转弯率 + Speed Kp × |低通车速| × 有效转弯率 / g`。第一项随转弯率增大，第二项随车速进一步增大。这里用小角度近似，转弯率以度每秒输入，算出的偏移以度表示。
5. **目标限幅和输出斜率。** 先按 `Lean Max` 裁剪新目标，绝对硬限为 10°。再限制每 5 ms 输出最多变化 `Slew dps × 0.005` 度。默认每拍 0.09°，从 0° 到约 6° 大约需要 0.33 s。启用条件普通失效时目标设为 0、清速度滤波，输出按斜率回零。STOP、串级复位及退出到保持平衡的路径可直接清零。

例如前进车速已稳定在 0.30 m/s，转弯率指令为 +30°/s。使用默认参数且未触及限幅时，目标为 `28 × (0.01 + 0.7 × 0.30 / 9.80665) ≈ +0.88°`。此时四个环节的值应分开看：计算目标约 +0.88°，斜率后的偏移逐拍向它靠拢，Roll 合成目标还要计入回收，实际侧倾由闭环跟踪。

## 3. 压弯如何落到电机

源码见 [control.c:900](../../code/Controller/control.c#L900)。

```c
static float roll_target_update(float zero, float recovery)
{
    s_roll_angle_target = g_roll_zero + constrain_float(zero + recovery - g_roll_zero,
                                                       -ROLL_TARGET_LIMIT,
                                                        ROLL_TARGET_LIMIT);
    return s_roll_angle_target;
}


//-------------------------------------------------------------------------------------------------------------------
static float roll_cascade_ctrl(float zero, uint8 run_angle, uint8 run20)
{
    float rcy = roll_recovery_offset(run20);         // 回收环给出的零点偏移(°)
    float angle_target = roll_target_update(zero, rcy);

    if (run_angle)
        pid_loc_calc(&r_angle_pid, att.roll - angle_target); // 回收与压弯合成目标限制在 ±10°
    roll_rate_ctrl((float)FLYWHEEL_OUT_LIMIT);               // 角速度环，增量式PI

    // 角度环不重复限幅，最终输出由角速度环限制。
    return r_rate_pid.out;
}

```

- 调用处先算 `g_roll_zero + LEAN_DIR × g_lean_offset`。当前 `LEAN_DIR=+1`，弯内侧倾的物理方向由车体与传感器坐标定义决定。
- `roll_recovery_offset()` 再加入飞轮回收偏移。压弯和回收的**合成偏移**限制在机械零点两侧 ±10°。例如压弯 +2°、回收 −1.5°，代表最终目标相对机械零点只偏 +0.5°。
- Roll 角度环使用 `att.roll - angle_target`，角速度环输出 `PWM_roll`。混控的飞轮 A、B 分别使用 `-roll_cmd + yaw_cmd` 与 `+roll_cmd + yaw_cmd`。Roll 优先占用输出，Yaw 使用双方剩余的共同余量。见 [混控代码](../../code/Controller/control.c#L1192)。

## 4. 菜单参数和观测量

| Params → Lean | 源码默认 | 范围 | 影响 |
|---|---:|---:|---|
| Turn Kp | 约 0.010 s | 0～0.10 s | 同样的转弯率下，提高方向预压弯。仍受低速淡入影响。 |
| Speed Kp | 0.70 | 0～2.00 | 提高随车速增长的侧倾项。 |
| Slew dps | 18°/s | 1～60°/s | 改变入弯、反向和正常回正的最大变化速度。 |
| Lean Max | 约 6° | 0～10° | 限制压弯幅值。设为 0 后目标归零，已有偏移按斜率收回。 |

参数定义见 [菜单](../../code/Menu/menu.c#L145)、[参数表](../../code/Common/param.c#L69) 和 [配置](../../code/config.h#L238)。

上位机 Run 帧先看 **CH9 目标转弯率**和实际车速判断输入，再看 **CH7 压弯偏移**。若 CH7 有变化而 **CH2 Roll 目标**变化很小，检查 **CH5 回收偏移**是否抵消，以及合成目标是否碰到限幅。最后用 **CH1 Roll 角**和 CH2 对比闭环跟踪。通道编号见 [上位机通道表](../../tools/unicycle_station/docs/channels.md)。

算法设计背景、旧参数迁移和实车对照方法见 [压弯控制说明](压弯控制说明.md)。
