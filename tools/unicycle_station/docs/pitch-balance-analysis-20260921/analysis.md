## 源码揭示的检查优先级

Pitch 外环使用 `encoder_counts_20ms - target_counts_20ms`，输出加入机械零点形成 Pitch 角目标，然后经角度环和增量式角速度环输出到 C 电机。方向必须在 IMU、执行器与编码器之间闭合为负反馈。

仅凭 Dir C=-1、Enc C=+1，不能判定编码器必然反向，它们是独立的接线极性补偿。但本次既更换主板又将原车尾作前向，必须优先实测。停车沿新前向转动行进轮，速度应为正；正向 Jog 应驱动轮子沿新前向滚动。在当前正速度环增益和 `反馈−目标` 公式下，正速度反馈会请求更大的 Pitch，因此更大的 Pitch 应对应向后的制动倾角；如果实际俯向新前方却使 Pitch 增大，则该坐标和速度环公式不能直接照用，不能靠增大 Kp 修复。

当前每米计数 11695，所以 `counts/20ms = 233.9 × speed_mps`：

| Speed Kp | 0.1m/s 的比例倾角 | 0.5m/s 的比例倾角 |
|---|---:|---:|
| 0.04 | 0.936° | 4.678° |
| 0.08 | 1.871° | 9.356°（会受到 ±8° 总输出限幅） |
| 0.01（后续对照起点） | 0.234° | 1.170° |

Speed Ki=0.004、积分状态限幅 200，积分倾角最大 ±0.8°。因此持续单向加速不能简单归结为“速度积分无限累积”；若零点误差比 0.8° 大，它也未必能靠这部分积分补偿。角速度环 Rate Ki 是另一条增量式输出累积，不能与速度环 Ki 混为一谈。

当前日志没有 Pitch 目标、速度环 P/I 输出、Pitch 角速度、C PWM、原始加速度或驱动电流。尚不能据此确定编码器反号、C 输出饱和、陀螺/加计动态偏差或电机力矩不足中的哪一个是根因。

## 推荐的实际操作

1. **停车验证三个方向。** 保持 `IMU Fwd=-1`，沿新前向手转轮子，确认 speed_actual>0；架空低 Duty 做 C Fwd，确认实际向新前向滚动。只修正不符合的 Enc C 或 Dir C，每项改完单独复核。再手动前俯/后仰看 Pitch 的增减，不能为了暂时平衡随意重复切换 IMU Fwd。
2. **隔离速度环。** 在横向支撑、限制行程条件下，进入 `Params → Pitch → Test Angle`。此模式实际旁路速度环，不需要改掉已记录的 Speed 增益。先沿用当前 Rate=20/1/0、Angle=12/0/0，以控制变量方式观察：轻微倾斜时轮子应向倾倒方向追赶，姿态有恢复趋势。单轴模式不控制 Roll，必须提供横向支撑；只控角度允许漂移，不能要求该阶段绝对原地不动。
3. **按 Angle 的结果分支。** 若一开就明显往相反方向拉倒，查 Dir C 与姿态方向，别继续加增益。若 Angle 仍有快抖或输出累积明显，先把 Rate Ki 从 1 回退到约 0.64 做对照，其他项固定；这只是试验起点，不是已验证的最优值。若控制偏软，再逐项评估 Rate Kp、Angle Kp，每次只改一项。
4. **重定机械零点。** 结构改变后，上一版本自动反号只保证旧坐标数学一致，不能保证新重心平衡点。用当前安装状态、重心大致在接地点上方的姿态作起点，静止读 Pitch；在角度环稳定前提下以 0.1～0.2° 小步调整，减少持续偏向一侧的驱动力。停车时日志中的约 33° 是当时摆放姿态，不能直接当平衡零点；也不能因为新固件默认 +3.7° 就强行覆盖实测 -4.5°。
5. **Angle 可控后再接速度环。** 先设置 `Speed Kp=0.01, Speed Ki=0, Speed Kd=0`，用受保护的短时 Test Speed 对照，不直接 Run。若一接速度环就比 Angle 更快单向发散，回到方向/公式检查。若能恢复速度但较慢，再每次增加 Speed Kp 约 0.002～0.005，看到往复振荡或回正后反冲就退回上一档。
6. **最后补速度积分。** 只有 P 已能压住速度、仍有稳定的小残余漂移时才加 Ki。上位机可从 0.0005 开始；当前 MCU 菜单 Speed Ki 步长为 0.001，车端从 0.001 做短时对照。每次停车后重开以清控制器状态，不建议直接恢复 0.004 来掩盖零点错误。

先解决“角度可控、速度不持续发散”，再讨论更严格的原地位置保持。当前 Balance 没有位置外环，即使速度环良好，也不能保证绝对停回同一地面位置。角度稳定与位置稳定不是同一个验证目标，相关理论可参考密歇根大学 [倒立摆控制教程](https://ctms.engin.umich.edu/CTMS/index.php?example=InvertedPendulum&section=ControlRootLocus)。

建议下一次记录分开做 Test Angle 和 Test Speed，保留参数读回，并注明是否手扶、实际向哪个方向移动。若需要继续定位内环，应另行补充 Pitch 目标、角速度、速度环输出和 C PWM 遥测；本次没有重新引入已撤回的 pitchdbg 扩展。
