历史源码、发行记录及原先纳入 Git 的截图/日志可从整理前提交 `d3d9c31` 及之前的历史查看。旧的安装包、重复截图和临时输出已从工作目录删除。二进制发行包不纳入 Git；需要历史程序时，应在独立目录检出对应源码并重新构建，历史产物不保证逐字节复现。

`app/` 是源码，`examples/` 是配置示例，`docs/` 保留使用说明与当前发行记录，`scripts/` 和 `tests/` 保留开发验证工具，`.venv/` 保留开发环境。`build/` 与 `artifacts/` 可重新生成。实际采集数据使用用户设置的会话目录，不属于本轮自动测试清理范围。

## 当前能力限制

- TCP/UDP/CAN/HID/Bluetooth、图像流和多设备并发保留扩展入口，本版实现串口、Mock 和日志回放。
- 参数控件支持通用类型；TC264D 本版线协议实际公开的固件参数为 float/int，字符串写入需要对应协议插件支持。
- 115200 UART2 不持续传相机图像。缺失的 Pitch 输出不会在 PC 端伪造。
- 波形时间轴为 PC 接收时间；CH0 用于回绕/遥测缺口估计。显示的数据年龄和配置 RTT 不能视为已测量的绝对单向链路时延。
- 3D 平滑仅修改显示；遥测过期停止插值。实际渲染性能受显卡/OpenGL 驱动影响。
- 回放采用磁盘稀疏索引和有上限的事件列表，极长会话最多展示前 10000 个事件；原始日志保留完整事件。
